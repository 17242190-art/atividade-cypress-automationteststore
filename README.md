Automação de Testes de Interface com Cypress
Descrição
Projeto desenvolvido para a disciplina de Teste de Software com o objetivo de automatizar funcionalidades da aplicação Automation Test Store utilizando Cypress.

Site testado:

https://automationteststore.com/

Funcionalidades Cobertas
Módulo 01 - Navegação e Organização da Interface
Validação da página inicial
Validação do menu principal
Verificação de categorias
Verificação da navegação disponível
Módulo 02 - Catálogo e Produtos
Exibição de produtos
Nome dos produtos
Campo de busca
Busca de produtos
Módulo 03 - Carrinho
Elementos do carrinho
Preços dos produtos
Acesso ao carrinho
Imagens dos produtos
Módulo 04 - Formulários
Preenchimento de busca
Disponibilidade do botão de busca
Módulo 05 - Responsividade
Visualização Desktop
Visualização Mobile
Tecnologias Utilizadas
Cypress
JavaScript
Node.js
Execução
Instalar dependências:

npm install
Executar todos os testes:

npx cypress run
Resultado
16 testes executados com sucesso.
